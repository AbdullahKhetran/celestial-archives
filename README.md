# Celestial Archives

A map and timeline of NASA hardware left on the Moon and Mars, built for the [NASA Space Apps Challenge 2026](https://www.spaceappschallenge.org/2026/challenges/nasas-discarded-equipment-storytelling/) challenge on discarded equipment.

**Live:** [celestial-archives-sigma.vercel.app](https://celestial-archives-sigma.vercel.app)

Coordinates, dates, and instrument lists are copied from NASA pages. When two NASA numbers disagree, both stay in the record. On the Moon the map uses the LROC-imaged claim. Missing coordinates are left blank. The map opens on the NASA LROC color mosaic. Mars uses the same archive on the ESA Mars Express colour mosaic.

## Tech stack

- Next.js, React, TypeScript, Tailwind CSS
- PostgreSQL with Drizzle ORM
- Google Gemini for event stories
- Zod for validation
- Deployed on Vercel
