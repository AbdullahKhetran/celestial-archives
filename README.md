# Celestial Archives

A map and timeline of NASA hardware left on the Moon and Mars. Coordinates, dates, and instrument lists are copied from NASA pages. When two NASA numbers disagree, both stay in the record. On the Moon the map uses the LROC-imaged claim. Missing coordinates are left blank.

The map opens on the Moon. Mars is the same archive behind the Mars tab. Small bodies and deep space are still to come.

## Start locally

Node.js 20 or newer.

```bash
npm install
npm run db:seed
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Setup details are in the [quickstart](docs/quickstart.md).
